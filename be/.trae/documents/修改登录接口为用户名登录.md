# 修改登录接口为用户名登录

## 1. 修改数据传输对象 (DTO)

修改 `LoginUserDto` 类，将 `email` 字段改为可选，添加 `username` 字段作为主要登录标识：

- 保留 `email` 字段但设为可选，保持向后兼容
- 添加 `username` 字段，使用 `IsString` 验证
- 确保密码字段仍然必填

## 2. 增强认证服务

在 `AuthService` 中添加和修改验证方法：

- 添加 `validateUserByUsername` 方法：根据用户名查找用户并验证密码
- 修改 `validateUser` 方法：支持同时通过邮箱或用户名查找用户
- 保持原有 `validateUserByPhone` 方法不变

## 3. 更新用户控制器

修改 `UserController.login` 方法：

- 使用修改后的 `LoginUserDto`
- 调用更新后的认证服务方法
- 保持接口路径和返回格式不变
- 确保安全验证逻辑完整

## 4. 测试和验证

- 确保用户名+密码登录功能正常
- 确保原有邮箱+密码登录功能仍然可用
- 确保登录失败时的错误信息正确
- 确保JWT令牌生成正常

## 5. 代码优化

- 更新JSDoc注释，反映接口变更
- 确保错误处理一致
- 保持代码风格统一

## 预期效果

- 用户可以使用用户名+密码成功登录
- 原有邮箱+密码登录功能保持不变
- 接口安全性和性能不受影响
- 不影响其他功能模块的正常运行
