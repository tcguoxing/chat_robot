# 登录注册功能加密传输实现计划

## 1. 需求分析
- 在用户执行登录或注册操作时，系统必须首先调用getPublicKey接口获取公钥
- 使用该公钥对用户输入的password进行非对称加密处理
- 将加密后的密码数据作为请求参数提交给后端服务器
- 确保整个加密传输过程符合安全标准，防止密码在传输过程中被泄露或篡改

## 3. 代码实现细节

### 3.1 API接口定义
```typescript
// 公钥响应数据类型
export interface PublicKeyResponse {
  code: number;
  message: string;
  data: {
    publicKey: string;
  };
}

// 获取公钥接口
export const getPublicKeyApi = async (): Promise<ApiResponse<{ publicKey: string }>> => {
  return request.get<{ publicKey: string }>('/auth/public-key');
};
```

### 3.2 加密工具函数
```typescript
// 创建加密实例
const encryptor = new JSEncrypt();

encryptor.setPublicKey(publicKey);
// 加密密码
const encryptedPassword = encryptor.encrypt(password);
```

### 3.3 登录流程修改
```typescript
const handleLogin = async () => {
  if (formRef.value) {
    formRef.value.validate(async (valid: boolean) => {
      if (valid) {
        loading.value = true;
        try {
          // 1. 获取公钥
          const publicKeyRes = await getPublicKeyApi();
          if (publicKeyRes.code !== 200) {
            throw new Error(publicKeyRes.message || '获取公钥失败');
          }
          
          // 2. 加密密码
          const encryptor = new JSEncrypt();
          encryptor.setPublicKey(publicKeyRes.data.publicKey);
          const encryptedPassword = encryptor.encrypt(loginForm.password);
          if (!encryptedPassword) {
            throw new Error('密码加密失败');
          }
          
          // 3. 准备登录请求参数
          const loginParams: LoginRequest = {
            email: loginForm.username, // 注意：根据swagger，登录接口使用email字段
            password: encryptedPassword,
          };
          
          // 4. 调用登录接口
          const loginRes = await loginApi(loginParams);
          if (loginRes.code === 200) {
            ElMessage.success(loginRes.message);
            console.log('登录成功:', loginRes.data);
            // 登录成功后跳转到内容页面
            router.push('/content');
          } else {
            ElMessage.error(loginRes.message || '登录失败');
          }
        } catch (err: any) {
          console.error('登录请求失败:', err);
          ElMessage.error(err.message || '登录请求失败，请稍后重试');
        } finally {
          loading.value = false;
        }
      } else {
        ElMessage.error('表单验证失败');
        return false;
      }
    });
  }
};
```

### 3.4 注册流程修改
```typescript
const handleRegister = async () => {
  if (formRef.value && !loading.value) {
    formRef.value.validate(async (valid: boolean) => {
      if (valid) {
        loading.value = true;
        try {
          // 1. 获取公钥
          const publicKeyRes = await getPublicKeyApi();
          if (publicKeyRes.code !== 200) {
            throw new Error(publicKeyRes.message || '获取公钥失败');
          }
          
          // 2. 加密密码
          const encryptor = new JSEncrypt();
          encryptor.setPublicKey(publicKeyRes.data.publicKey);
          const encryptedPassword = encryptor.encrypt(registerForm.password);
          if (!encryptedPassword) {
            throw new Error('密码加密失败');
          }
          
          // 3. 准备注册请求参数
          const registerParams: RegisterRequest = {
            username: registerForm.username,
            password: encryptedPassword,
            email: registerForm.email,
            phone: registerForm.phone,
            inviteCode: registerForm.inviteCode
          };
          
          // 4. 调用注册接口
          const registerRes = await registerApi(registerParams);
          if (registerRes.code === 200) {
            ElMessage.success(registerRes.message);
            console.log('注册成功:', registerRes.data);
            // 注册成功后跳转到登录页面
            router.push('/');
          } else {
            ElMessage.error(registerRes.message || '注册失败');
          }
        } catch (err: any) {
          console.error('注册请求失败:', err);
          ElMessage.error(err.message || '注册请求失败，请稍后重试');
        } finally {
          loading.value = false;
        }
      } else {
        ElMessage.error('表单验证失败，请检查输入');
        return false;
      }
    });
  }
};
```
