# 实现毛玻璃效果登录页面

## 技术栈
- Vue3 + TypeScript + Vite
- Element Plus 组件库

## 实现步骤

1. **修改 main.ts**
   - 引入 Element Plus 及其样式
   - 配置 Element Plus

2. **创建登录组件**
   - 在 components 目录下创建 Login.vue 组件
   - 实现登录表单，包括用户名、密码输入框和登录按钮
   - 添加表单验证

3. **实现毛玻璃效果**
   - 修改 App.vue 为主容器，添加背景图片
   - 为登录表单容器添加毛玻璃效果样式
   - 调整整体布局，使登录表单居中显示

4. **样式优化**
   - 调整表单元素样式，使其符合毛玻璃效果的视觉风格
   - 添加适当的动画效果，提升用户体验
   - 确保响应式设计，适配不同屏幕尺寸

5. **功能完善**
   - 实现登录按钮点击事件
   - 添加表单验证逻辑
   - 模拟登录请求（可选）

## 预期效果
- 具有毛玻璃效果的登录表单
- 居中显示的登录界面
- 清晰的
